Image Test

Three ways of dropping docs/images/tools.jpg into a page, all using the site's existing ice/granite tokens. Resize the window or toggle light/dark mode to see how each one holds up.

1. Framed figure with caption

Matches the bordered "card" look used for mode cards and control lists elsewhere on the site. Best for screenshots or gameplay captures that need a caption.

<figure class="figure"> <img src="/docs/images/tools.jpg" alt="..."> <figcaption>Caption text here</figcaption> </figure>

2. Bare image, no frame

Just a rounded-corner image with no card around it. Reads more like a hero or inline illustration than a documented screenshot.

<img class="bare-img" src="/docs/images/tools.jpg" alt="...">

3. Constrained & centered

Caps the width and centers the image — useful for a portrait-oriented shot like this one, so it doesn't stretch full-width and dominate the page.

<div class="figure contained"> <img src="/docs/images/tools.jpg" alt="..."> <figcaption>Caption text here</figcaption> </div>
